## Architecture Highlights

### Search
- Sử dụng raw SQL để query FTS5 virtual table (SeaORM không có native FTS5 support)
- Auto-prefix matching cho incremental search (`"bat"` → `"bat*"`)
- FTS5 `rank` score trả về để sắp xếp theo relevance

### Virtualization
- **Keyset pagination** thay vì offset-based: `WHERE id < cursor` là O(1) cho mọi vị trí, trong khi `OFFSET N` là O(N)
- **TanStack Virtual** chỉ render rows trong viewport + overscan (10 rows cho table, 3 rows cho grid)
- **Infinite scroll** tự động load batch tiếp theo khi user scroll gần cuối
- **Memory footprint phẳng**: DOM chỉ chứa ~20-30 elements bất kể dataset 10M+

### Grid Design
- Gradient cover từ `oklch()` color space — deterministic từ title hash, visually pleasing
- Responsive grid: 2 → 3 → 4 → 5 columns theo viewport width
- ResizeObserver cho dynamic column count trong virtualizer
