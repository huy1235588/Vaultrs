## Architecture Highlights

### CollectionSettings
- **3 JSON groups** (appearance/media/behavior) — mở rộng không cần migration
- **Auto-create trigger** — khi tạo Collection mới, settings được tạo tự động với defaults
- **Forward-compatible parsing** — `serde(default)` cho tất cả fields, nên JSON cũ vẫn parse được khi thêm settings mới
- **Seed migration** — tạo settings cho tất cả Collections hiện có

### Assets System
- **Dual-source** — LOCAL (file import) + REMOTE (URL reference)
- **7 roles** — 4 Singular (COVER, BACKGROUND, LOGO, BANNER) + 3 Plural (GALLERY, SCREENSHOT, ATTACHMENT)
- **Partial unique indexes** — enforce max 1 asset per singular role per item ở tầng database
- **Singular role auto-replace** — khi set cover mới, cover cũ bị unlink tự động
- **Batch cover query** — `get_covers_batch(item_ids)` cho Grid/List view performance
- **Thumbnail generation** — WebP output, Lanczos3 resize, 300×450 max, chạy sync tại thời điểm upload

### VaultStorage
- **UUID filenames** — tránh collision và path traversal
- **SHA-256 checksums** — integrity verification
- **Relative paths** — portable vault, có thể di chuyển giữa các máy
- **Structure**: `vault-storage/originals/{uuid}.{ext}`, `vault-storage/thumbnails/{uuid}_thumb.webp`
