# Walkthrough — Phase 3: Item Detail & Custom Fields Management

Triển khai hoàn chỉnh tính năng quản lý Custom Fields (Attributes) và trang chi tiết Item Detail Page, hoàn thiện luồng nghiệp vụ lõi (EAV dynamic schema) của ứng dụng Vaultrs. Giao diện được thiết kế hiện đại, mượt mà và tối ưu hóa tối đa cho desktop UX.

---

## Changes Made

### 1. UI Foundation (7 components)
Tích hợp các base components từ shadcn/ui để phục vụ thiết kế form và các bộ chọn dynamic:
- `select` (Radix Select wrapper)
- `textarea` (Auto-sizing/field-sizing textarea)
- `badge` (Visual indicator/pills)
- `separator` (Visual hierarchy)
- `label` (Form labels)
- `checkbox` (Input checklist validation)
- `switch` (Yes/No boolean toggle)

*Lưu ý: Đã fix triệt để lỗi import alias `"src/lib/utils"` do shadcn sinh tự động thành `"@/lib/utils"` tương thích với Vite config.*

### 2. State & Navigation Layer (2 contexts)
- **[CollectionContext](file:///d:/Project/Rust/Vaultrs/desktop/src/core/context/CollectionContext.tsx)**: Mở rộng thêm state `attributes[]` và `attributesLoading`. Tự động fetch danh sách custom fields khi user chuyển đổi collection. Cung cấp các actions: `addAttribute`, `editAttribute`, `removeAttribute` đồng bộ trực tiếp với Tauri IPC backend command.
- **[ItemContext](file:///d:/Project/Rust/Vaultrs/desktop/src/core/context/ItemContext.tsx) [NEW]**: Quản lý state điều hướng của Item được chọn (`selectedItem`, `itemLoading`). Hỗ trợ luồng fetch/load chi tiết item trực tiếp từ database khi click row và clear quay lại danh sách.

### 3. Custom Fields Management (4 files)
Giao diện quản lý schema cho từng Collection:
- **[AttributeManager.tsx](file:///d:/Project/Rust/Vaultrs/desktop/src/components/Attribute/AttributeManager.tsx) [NEW]**: Dialog quản lý danh sách fields của collection hiện tại. Hỗ trợ sắp xếp thứ tự hiển thị bằng nút `Up` / `Down` (đổi `display_order` trực tiếp trong DB).
- **[CreateAttributeDialog.tsx](file:///d:/Project/Rust/Vaultrs/desktop/src/components/Attribute/CreateAttributeDialog.tsx) [NEW]**: Form tạo mới field. Hỗ trợ tự động slugify tên field thành database key (snake_case). Sử dụng `OptionsTagInput` cho cấu hình options và các checkbox Required / Searchable.
- **[EditAttributeDialog.tsx](file:///d:/Project/Rust/Vaultrs/desktop/src/components/Attribute/EditAttributeDialog.tsx) [NEW]**: Sửa Name, Options (thông qua `OptionsTagInput`), Required, Searchable. Khóa trường Key và Type để đảm bảo toàn vẹn dữ liệu.
- **[DeleteAttributeDialog.tsx](file:///d:/Project/Rust/Vaultrs/desktop/src/components/Attribute/DeleteAttributeDialog.tsx) [NEW]**: Cảnh báo nguy hiểm khi xóa trường dữ liệu.
- **[OptionsTagInput.tsx](file:///d:/Project/Rust/Vaultrs/desktop/src/components/Attribute/OptionsTagInput.tsx) [NEW]**: Component dùng chung nhập Tag/Chip động cho lựa chọn của các trường `select` & `multiselect` (hỗ trợ nhập, dán danh sách ngăn cách bởi dấu phẩy, dùng phím Enter/Comma/Backspace).
- **[attributeFieldTypes.ts](file:///d:/Project/Rust/Vaultrs/desktop/src/components/Attribute/attributeFieldTypes.ts) [NEW]**: Chứa metadata định nghĩa danh sách các kiểu trường (`FIELD_TYPES`), nhãn hiển thị, mô tả chi tiết, và icons tương ứng từ thư viện Lucide để dùng chung cho các màn hình.

### 4. Item Detail & Fields Editor (3 files)
- **[ItemDetailPage.tsx](file:///d:/Project/Rust/Vaultrs/desktop/src/pages/ItemDetailPage.tsx) [NEW]**: Giao diện chi tiết thiết kế 2-panel cao cấp (Left: title & scrollable custom field editor; Right: metadata sidebar, created/updated timestamps, validation errors list). Hỗ trợ nút `Save` nổi bật chỉ active khi có thay đổi thực tế (`hasChanges`).
- **[DynamicField.tsx](file:///d:/Project/Rust/Vaultrs/desktop/src/components/Item/DynamicField.tsx) [NEW]**: Renderer thông minh tự động map kiểu dữ liệu thuộc tính sang component phù hợp:
  - `text` → Input text
  - `textarea` → Textarea
  - `number`/`decimal` → Input number
  - `date`/`datetime` → Date selectors
  - `checkbox` → Switch toggler
  - `select` → Shadcn dropdown
  - `multiselect` → Checkable pills grid (click để toggle tag rất mượt mà)
  - `url` → Input có kèm nút preview mở trình duyệt bên ngoài
- **[DeleteItemDialog.tsx](file:///d:/Project/Rust/Vaultrs/desktop/src/components/Item/DeleteItemDialog.tsx) [NEW]**: Hộp thoại xác nhận xóa item.

### 5. Integration & Navigation (4 files)

- **[Sidebar.tsx](file:///d:/Project/Rust/Vaultrs/desktop/src/components/Layout/Sidebar.tsx)**: Thêm tùy chọn "Manage Fields" trong context menu của từng collection.
