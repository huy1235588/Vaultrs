## Architecture Notes

- **Routing**: Dùng conditional rendering dựa trên `selectedCollection` trong context (không cần react-router ở phase này)
- **Header ↔ CollectionPage communication**: Sử dụng `React.MutableRefObject` để Header button trigger dialog trong CollectionPage mà không cần lift state quá cao
- **ItemTable refresh**: Dùng `refreshKey` pattern — parent increment key sau khi create item thành công → trigger useEffect refetch
