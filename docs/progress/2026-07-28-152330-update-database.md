Cập nhật toàn diện tài liệu [database-design-specification.md](file:///d:/Project/Rust/Vaultrs/docs/02-database/database-design-specification.md) (302 → 434 dòng) để hỗ trợ multi-role assets, dual-source media (Local/Remote), CollectionSettings tách riêng, và default cover fallback — trong khi **giữ nguyên mô hình lõi `Items → ItemAssets → Assets`**.

## Thay đổi chính

### 1. Entity mới: `CollectionSettings` (Section 2.1.1)
- Bảng 1-1 với `Collections`, chứa settings nhóm theo 3 cột JSON: `appearance`, `media`, `behavior`
- `media_enabled` được chuyển từ `Collections` sang `CollectionSettings.media`
- Bổ sung `cover_enabled`, `default_cover_mode` (SYSTEM/CUSTOM/NONE), `default_cover_asset_id`, `allowed_roles`
- Giải thích chi tiết rationale tách bảng và cơ chế Default Cover fallback

### 2. Entity sửa đổi: `Assets` (Section 2.5)
- Thêm `source_type` (`LOCAL` | `REMOTE`), `source_url`, `local_cache_path`
- `relative_path`, `file_size_bytes`, `checksum` trở thành nullable (tuỳ `source_type`)
- `state` thêm giá trị `CACHED` cho Asset remote đã cache xong
- Mô tả chi tiết luồng xử lý LOCAL vs REMOTE, cơ chế cache, ưu tiên nguồn khi render

### 3. Entity sửa đổi: `ItemAssets` (Section 2.6)
- Mở rộng `role` từ `{COVER, ATTACHMENT}` → 7 giá trị với 2 nhóm:
  - **Singular** (max 1/Item): `COVER`, `BACKGROUND`, `LOGO`, `BANNER`
  - **Plural** (không giới hạn): `GALLERY`, `SCREENSHOT`, `ATTACHMENT`

### 4. Entity sửa đổi: `Collections` (Section 2.1)
- Loại bỏ cột `media_enabled` (chuyển sang CollectionSettings)

### 5. Cập nhật các section hỗ trợ
- **Section 3 (Relationships):** Thêm 2 quan hệ mới (CollectionSettings), mở rộng mô tả Items → ItemAssets
- **Section 4 (Indexes):** Thêm 5 index mới (1 CollectionSettings, 3 Singular Role partial unique, 1 composite `source_type+state`)
- **Section 5 (Constraints):** Thêm 7 constraint mới cho CollectionSettings, source_type, Singular Roles
- **Section 6 (Performance):** Thêm 3 bullet mới (default cover fallback, remote cache priority, CollectionSettings caching)
- **Section 7 (Large Dataset):** Thêm 2 bullet (default cover không tạo ItemAssets, remote orphan cleanup)
- **Section 8 (Normalization):** Thêm CollectionSettings vào phân tích, nâng từ 2 → 3 điểm denormalization
- **Section 9 (Trade-offs):** Thêm 4 mục mới (Singular Role, Remote Assets, CollectionSettings JSON, Default Cover)
